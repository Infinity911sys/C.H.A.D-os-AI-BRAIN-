# Algo-Traj Play Store release scaffolding

This repository includes the first-step scaffolding for a Play Store compliant release path:

- standalone web manifest in `/website/manifest.webmanifest`
- standalone product website in `/website`
- privacy page in `/website/privacy.html`
- support page in `/website/support.html`
- release summary page in `/website/play-store.html`

## Remaining release tasks

- package Algo-Traj in an Android release container or wrapper
- generate signing-ready Android artifacts
- prepare store graphics, screenshots, and feature artwork
- finalize privacy/data safety disclosures
- publish public support contact information

## Current intent

The repository now treats Algo-Traj as the first system to move from concept registry into product-facing operational scaffolding.
